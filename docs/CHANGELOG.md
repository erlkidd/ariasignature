## [0.8.5] - 2026-05-02

### Changed

- Типографика и вертикальный ритм интерфейса: единая шкала кегля, отступы между секциями и блоками панели.
- Вкладка «О системе»: сведения в таблицах параметр / значение, секции в визуальных блоках.

- Настройки: подпись «Обновление дисков» вместо «Обновление SMART»; краткая подсказка для исходящей синхронизации; расписание POST с теми же пресетами, что и опрос дисков (расширенный Quartz отдельно).
- Исходящий POST на коллектор без `Authorization` и без пользовательских заголовков из настроек; соответствующие поля убраны из API и UI.

### Fixed

- Файловая архивация `.1CD`: внутри RAR файл называется как у источника (например `1Cv8.1CD`), без префикса GUID во временной копии.

### Docs

- Обновлены `API.md`, `USER_GUIDE.md`, `DEVELOPER_GUIDE.md`, версии в сопутствующих документах.

## [0.7.0] - 2026-05-02

### Added
- Вкладка «О системе» (перед «Диски»): hostname, DNS, адреса сетевых интерфейсов, ОС, CPU, ОЗУ, видеокарты (Windows/WMI).
- `GET /api/v1/system` — JSON-снимок системы для UI и интеграций.
- Исходящая синхронизация на коллектор: настройки в SQLite/UI (`OutboundSync:*`), Quartz job периодически выполняет `POST` на заданный URL с телом JSON (`system`, `disks`, `backups.jobs`, `backups.recentLogs`). Опционально: Bearer token и один пользовательский заголовок (имя + значение). Локальный входящий API по-прежнему без этих токенов.
- Перепланирование cron исходящей отправки при `PUT /settings` и синхронизация триггера с БД при старте службы.

### Docs
- Обновлены `API.md`, `USER_GUIDE.md`, `DEVELOPER_GUIDE.md`, `DEVELOPMENT_NOTES.md` и версии сопутствующих документов.

## [0.3.0] - 2026-05-02

### Changed
- Расписание опроса дисков по умолчанию: раз в час (`0 0 * * * ?`); прогрев при старте службы обновляет только таблицу дисков без записи в историю `SmartMetrics`; кнопка «Обновить данные», Quartz и расписание по-прежнему добавляют точки истории.
- Усечение истории SMART: до ~200 последних записей на диск и общий потолок 1200 строк.
- Панель: вкладка «Активные задачи» включает текущий запуск даже при отключённой задаче; нейтральный пустой экран; статусы архивации в интерфейсе на русском; построение и разбор cron для дисков (в т.ч. «каждый час» без неверного `*/60`); подсказки для ручного Quartz-cron.
- MSSQL: для `BACKUP DATABASE` снято ограничение времени выполнения команды; сообщение о SQL-таймауте формулируется по-русски.
- Окно панели: при старте сразу показывается экран «Загрузка…» вместо пустого белого WebView2 до готовности API.

### Fixed
- Файловая архивация: промежуточная копия во временном каталоге `%TEMP%\AriaSignature` с удалением в `finally`; в каталоге архивов остаётся целевой `.rar`. Ретраи сервиса не повторяются при блокировке или ошибке доступа к исходнику/временному файлу. Сообщения об ошибке различают чтение исходника и запись временной копии.
- Несколько резервных копий одновременно: в UI отображаются все запущенные задачи; планировщик за один тик параллельно выполняет все попавшие в окно cron задачи (`Task.WhenAll`).
- Текст пустого списка вкладки «Активные задачи» без уточнения в скобках.
- Окно панели: нативный WPF‑оверлей при старте до готовности WebView2 и до загрузки `http://127.0.0.1…`; более заметная HTML‑заглушка; короткий таймаут запроса порта API; таймаут инициализации WebView2 (2 мин) с сообщением.

### Docs
- Обновлены `API.md` (cron по умолчанию, прогрев, история, вкладка активных задач) и версии документов.
