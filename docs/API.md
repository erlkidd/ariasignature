# Документация API AriaSignature

## Базовые параметры

- Базовый URL: `http://127.0.0.1:{port}/api/v1`
- Порт по умолчанию: `5160`
- Формат данных: `application/json`

## Endpoints

### Состояние сервиса

- `GET /status` — текущее состояние сервиса и время ответа.

### Диски

- `GET /disks` — список обнаруженных накопителей.
- `GET /disks/{id}` — сведения о диске по идентификатору.
  - если диск не найден: `404` + `application/problem+json`.

### SMART

- `GET /disks/{id}/smart` — история SMART-метрик по диску.
  - если диск не найден: `404` + `application/problem+json`.

### Архивация

- `GET /backups` — список задач архивации.
- `POST /backups` — создание задачи архивации.
- `PUT /backups/{id}` — обновление задачи архивации.
- `DELETE /backups/{id}` — удаление задачи архивации.
  - если задача не найдена: `404` + `application/problem+json`.
- `POST /backups/{id}/run` — ручной запуск задачи.

### Логи архивации

- `GET /backups/logs` — список логов выполнения задач.

## Типы задач архивации

- `File`:
  - `Source` — путь к файлу базы (`.1CD` или другой файл/источник);
  - `Destination` — папка назначения.
- `MsSql`:
  - `Source` — строка подключения к SQL Server;
  - `Destination` — папка назначения архивного результата.

## Валидация запросов архивации

- Проверка обязательных полей.
- Проверка корректности cron-выражения.
- Проверка `RetentionCount > 0`.
- Проверка абсолютных путей источника/назначения в файловых сценариях.
- Для `File`:
  - источник должен существовать;
  - source/destination не должны конфликтовать.
- Для `MsSql`:
  - строка подключения должна содержать `Server` и `Database`/`Initial Catalog`;
  - выполняется онлайн-проверка доступности подключения/базы.
- Проверка доступа к папке назначения (включая тест записи).

## Формат ошибок

- Ошибки валидации: `400` с телом в формате validation problem.
- Ошибки not found: `404` с `application/problem+json`.
- Неперехваченные ошибки: `500` с `application/problem+json` и `traceId`.

## OpenAPI

- Swagger UI: `/swagger`
- OpenAPI-описание: через endpoint Swagger.

## Примечания

- API предназначен для локального сервисного контура на Windows.
- Данные сохраняются в SQLite (`ConnectionStrings:AriaSignature`).
- Результаты архивации формируются как `.rar`; отсутствие архиватора отражается в логе выполнения задачи.
