# Installation and First Start

## RU

### Установка

Поддерживаются installer/packages/OPM/docker сценарии (в зависимости от окружения).

### Минимальный старт

```powershell
melezh CreateProject --path C:\temp\demo.melezh
melezh RunProject --proj C:\temp\demo.melezh --port 7788
```

Далее проверь:

- API endpoint: `http://localhost:7788/<handler>`
- Web UI: `http://localhost:7788/ui`
