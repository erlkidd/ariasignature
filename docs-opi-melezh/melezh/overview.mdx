# Overview

## RU

Melezh принимает HTTP-запросы, преобразует их в вызовы `oint` (или расширений) и возвращает результат в унифицированном формате.

Ключевые возможности:

- endpoint-обработчики для функций OInt
- значения параметров по умолчанию
- strict-параметры для защиты чувствительных данных
- встроенный Web UI и логирование

## EN

Melezh receives HTTP requests, converts them into `oint` (or extension) calls, and returns normalized responses.

Core capabilities:

- endpoint handlers for OInt functions
- default argument values
- strict arguments for sensitive parameters
- built-in Web UI and request logging
