# Logging and Debugging

## RU

Чеклист диагностики:

1. Проверить запуск сервиса и порт.
2. Проверить существование handler и его статус.
3. Сопоставить входной запрос и фактические аргументы.
4. Проверить downstream ошибку (OInt/external API).
5. Повторить минимальный запрос.

## EN

Diagnostics checklist:

1. Validate service startup and port binding.
2. Validate handler existence and status.
3. Compare incoming request with resolved arguments.
4. Inspect downstream failure (OInt/external API).
5. Reproduce with minimal request.
