# Project Setup

## RU

Основные команды раздела `Projects-setup`:

- `CreateProject`
- `FillProjectSettings`
- `SetProjectSetting`
- `GetProjectSettings`
- `UpdateUIPassword`
- `RunProject`

Практика:

1. Сначала `FillProjectSettings`.
2. Затем точечно `SetProjectSetting`.
3. После запуска проверяй `GetProjectSettings`.

## EN

- `CreateProject`
