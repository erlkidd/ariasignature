# Handlers and Arguments

## RU

Handler-поток:

1. `AddRequestsHandler`
2. `SetHandlerArgument` (при необходимости `strict`)
3. `EnableRequestsHandler` / `DisableRequestsHandler`
4. `UpdateRequestsHandler` или `UpdateHandlersKey`

Советы:

- для секретов используй дефолтные аргументы на стороне Melezh
- публичному клиенту отдавай только безопасные параметры

## EN

Handler lifecycle:

1. `AddRequestsHandler`
2. `SetHandlerArgument` (use `strict` when needed)
3. `EnableRequestsHandler` / `DisableRequestsHandler`
4. `UpdateRequestsHandler` or `UpdateHandlersKey`

Tips:

- keep sensitive values as server-side defaults
- expose only safe client-facing parameters
