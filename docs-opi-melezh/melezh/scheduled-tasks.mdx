# Scheduled Tasks

## RU

Раздел автоматизации:

- `AddScheduledTask`
- `GetScheduledTask`
- `GetScheduledTaskList`
- `UpdateScheduledTask`
- `EnableScheduledTask` / `DisableScheduledTask`
- `DeleteScheduledTask`

Рекомендуется начинать с одного тестового задания и включать его только после проверки логов.

## EN

Automation command set:

- `AddScheduledTask`
- `GetScheduledTask`
- `GetScheduledTaskList`
- `UpdateScheduledTask`
- `EnableScheduledTask` / `DisableScheduledTask`
- `DeleteScheduledTask`

Start with one test task and enable it only after validating logs.
