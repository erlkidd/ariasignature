# Getting Started

## RU

### Что такое OInt

OpenIntegrations предоставляет единый набор модулей для интеграции 1C/OneScript/CLI с внешними API, БД и сетевыми протоколами.

### Минимальный путь старта

1. Выбери runtime: `1C`, `OneScript` или `CLI`.
2. Установи релизный артефакт (не промежуточный код из main).
3. Проверь один базовый вызов (например Telegram send/get или HTTP request).
4. Добавь обработку ошибок и логирование.

### Первый пример (CLI)

```bash
oint telegram SendTextMessage --token "***" --chat 123456 --text "hello"
```

## EN

### What OInt is

OpenIntegrations provides a unified module set to integrate 1C/OneScript/CLI with external APIs, databases, and transport protocols.

### Fastest onboarding path

1. Pick runtime: `1C`, `OneScript`, or `CLI`.
2. Install release artifact (not in-progress main branch snapshot).
3. Validate one baseline call.
4. Add error handling and logging.

### First example (CLI)

```bash
oint telegram SendTextMessage --token "***" --chat 123456 --text "hello"
```
