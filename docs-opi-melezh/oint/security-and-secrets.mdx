# Security and Secrets

## RU

### Базовые правила

- не храни токены в открытых примерах
- не логируй секреты в runtime-логах
- используй переменные окружения/секрет-хранилище
- регулярно обновляй ключи и токены

### Для OInt

- перед публикацией команд CLI удаляй значения `--token`, `--key`, `--secret`
- для handler-ориентированных сценариев предпочитай значения по умолчанию на стороне сервера

## EN

### Baseline rules

- never expose tokens in shared examples
- never print secrets in runtime logs
- use env vars or secret storage
- rotate credentials regularly

### OInt-specific hints

- scrub `--token`, `--key`, `--secret` before sharing CLI commands
- prefer server-side defaults for handler-based setups
