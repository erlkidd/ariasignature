# Databases

## RU

### Поддерживаемые БД

- PostgreSQL
- SQLite
- MSSQL
- MySQL
- ClickHouse
- MongoDB

### Практика подключения

1. Проверка подключения коротким запросом.
2. Выполнение бизнес-запросов с параметрами.
3. Разделение DDL и DML сценариев.
4. Логирование SQL-ошибок с контекстом.

## EN

### Supported databases

- PostgreSQL
- SQLite
- MSSQL
- MySQL
- ClickHouse
- MongoDB

### Connection practice

1. Validate connectivity with a lightweight query.
2. Use parameterized business queries.
3. Keep schema and data operations separate.
4. Log query failures with enough context.
