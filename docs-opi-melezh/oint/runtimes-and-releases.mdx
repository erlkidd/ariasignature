# Runtimes and Release Variants

## RU

### Поддерживаемые варианты

- Расширение 1C (`cfe`, XML, EDT)
- OneScript пакет (`ospx`)
- CLI приложение (`exe`, `rpm`, `deb`, и др.)

### Как выбрать runtime

- `1C`: если логика внутри прикладной конфигурации.
- `OneScript`: если нужен скриптовый раннер с BSL-синтаксисом.
- `CLI`: если нужна автоматизация из shell/CI.

### Важный принцип

Всегда ориентируйся на release-артефакты и совместимую версию.

## EN

### Supported options

- 1C extension (`cfe`, XML, EDT)
- OneScript package (`ospx`)
- CLI app (`exe`, `rpm`, `deb`, etc.)

### Runtime decision

- `1C`: business logic in 1C configuration.
- `OneScript`: script runtime with BSL syntax.
- `CLI`: shell/CI automation.

### Important rule

Prefer tagged release artifacts and compatible versions.
